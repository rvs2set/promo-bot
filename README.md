# Telegram Promo Bot

Чат-бот для проведения промо-акций и ежедневных розыгрышей
ссылка:https://t.me/my_git_promo_bot

## Функционал
- Выдача уникальных промокодов пользователям.
- Автоматическая проверка подписки на канал партнера
- Ежедневные розыгрыши и накопительная система шансов (до 10 шансов)
- Личный кабинет («Мои шансы»)
- Администрирование и сбор контактов победителей

## Стек технологий
- Python 3.11+
- aiogram 3.x
- SQLAlchemy / SQLite (PostgreSQL)
